# Bayesian Regression Models

These scripts fit the primary models used to test associations between transposable elements (TEs) and nucleotide diversity (π) in non-overlapping 10 kb genomic windows.

## Input

All models used the `genome_10kb_pi.tsv` as input, generated by the fixed-window workflow in [`02_Repeats/05_Repeats_Fixed_Windows/`](../02_Repeats/05_Repeats_Fixed_Windows/). The table contains window-level π, chromosome, TE presence, TE fraction, repeat order/class, and mean CpG-adjusted Kimura divergence. Fitted models are written to its `brms_models/` subdirectory.

## Models

| Script | Model | Data subset | Question |
|---|---|---|---|
| `03_q1_brms.R` | `PI ~ TE_PRESENT + CHROM` | All windows | Does π differ between windows with and without TEs after accounting for chromosome? |
| `04_q2_brms.R` | `PI ~ CHROM + ORDER + TE_FRACTION` | TE-containing windows, expanded by repeat order | Does π vary among TE orders and with the fraction of each window occupied by TEs? |
| `04_q2_brms.R` | `PI ~ CHROM + CLASS + TE_FRACTION` | TE-containing windows, expanded by repeat class | Does π vary among TE classes and with TE fraction? |
| `05_q3_brms.R` | `PI ~ KIMURA_SCALED + CHROM` | TE-containing windows with finite mean Kimura values | Does π vary with standardized TE age after accounting for chromosome? |

Q2 and Q2b expand order or class annotations so windows overlapping multiple categories contribute one row per category.

## Shared settings

All models use a lognormal response distribution with four chains, four cores, 4,000 iterations per chain, 2,000 warmup iterations.

Priors are:

```r
prior(normal(0, 2), class = "b")
prior(student_t(3, 0, 2.5), class = "Intercept")
prior(exponential(1), class = "sigma")
```

The fitted model files are named `q1_te_presence`, `q2_te_order`, `q2_te_class`, and `q3_kimura_age`.
